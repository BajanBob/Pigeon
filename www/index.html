Import WSJT-X decodes

Paste decode lines from WSJT-X (the Band Activity pane, or lines from ALL.txt). Einstein parses mode, SNR, dT, frequency and the callsign/grid from the message, and adds them to your log — a cross-platform way to capture real FT8/FT4/Q65/MSK144/WSPR decodes without extra software.

Live capture over WSJT-X's UDP broadcast, rigctld (Hamlib) CAT control, and PSK Reporter spotting need raw network sockets — those run in the desktop (Windows/Linux) build's helper and are the next phase; the log, analysis and import here work on every platform.

SSP — Sea Scatter Propagation analysis (2 m / 70 cm)

AI-assisted over-water VHF/UHF path analysis. Aggregates the marine-weather variables that drive ducting and sea scatter along the great-circle path between two grid squares, and predicts a workable-path likelihood by distance band. Honest by design: 2 m/70 cm do not propagate thousands of miles by these mechanisms — long bands are capped at the documented physical ceiling and reported near zero.

Marine weather along path

Fetched live per waypoint (Open-Meteo marine, no key). If offline, enter a representative set and it will be applied to the whole path.

Cognitive engine — AI-driven link & propagation

Einstein senses its operational theatre from the stations and sounding beacons it hears, then decides — with reasons you can read: it classifies each path (F2 / Es / Tropo-duct / TEP / tropo-scatter / meteor / ground-wave), maps which directions are open, and throttles the modem FEC/speed up or down (with redundancy failover) to hold a link. Explainable, not a black box.

Einstein Beacon — hail & chat

Hail other stations with a named Einstein Beacon (callsign + grid + capabilities), as a CQ or to a specific call, on VHF/HF digital frequencies. On contact, the two radios negotiate the fastest modem both support that the SNR allows, then open a live clear-text chat.

Einstein Email & Modem

Clear-text RF email / messaging over an SSB rig, carried by the built-in Einstein Modem (adaptive OFDM). Compose here; the waveform is generated and decoded by the rf/ tools (einstein_modem.py + einstein_email.py) on the SDR/soundcard host.

How it sends

Einstein Email compresses (zlib, reversible — not a cipher), splits the message into CRC-protected blocks, and runs a selective ARQ: the receiver asks only for the blocks that failed, so traffic gets through fading that would wipe a single pass. Pro lifts the airtime governor and uses 16-QAM over ~2.4 kHz for ~5× the throughput of Standard.

Full spec, measured FER/throughput and the recommended innovations: rf/MODEM.md.

Station setup

Grid square is required — Einstein's propagation, SSP and cognitive engine all work from it. The computer IP is auto-detected for the desktop link and modem networking (edit if wrong).

Everything is stored on this device only. A valid grid unlocks the SSP and AI tabs.

Radio / CAT — desktop station engine

Pick your radio and Einstein auto-fills the CAT/PTT settings — CI-V address, CAT baud, PTT method and rigctld — the same tested values as Tradewind. These drive the native station engine (rf/einstein_station.py) for keying, tuning and the modems on the Windows/Linux/Pi build.

The drift classifier subtracts your reference drift from the measured offset before testing for the sea Bragg Doppler — so a disciplined reference lets Einstein tell sea Doppler from rig drift.

Audio for analysis works now, in-app: the Analyzer and Recorder tabs use your browser's audio input (getUserMedia) — feed the rig's USB-codec / line-in into the computer and watch the band live on any platform. Native soundcard TX/PTT/CAT (the previously-missing pipe) runs on the desktop build via these saved settings: python3 rf/einstein_station.py --radio <id> --info to check wiring, --analyze 3 to pipe rig audio straight into SSP/drift analysis, --tune, --tx-test, --rx for on-air use.

About

Einstein is a weak-signal station companion: an honest logging and analysis tool that works alongside WSJT-X and Hamlib rather than re-implementing their decoders. Modes you log include WSPR, FT8, FT4, MSK144, Q65, FST4W, JT65, 2 m / 70 cm EME, meteor scatter and troposcatter. Data stays on your device; export ADIF for your main logbook.
